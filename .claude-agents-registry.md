## 🚀 How to Use These Agents

### Single Agent (Ad-hoc)
```
User: "Add DAW feature X"
↓
Copilot Chat automatically routes → DAW Specialist
↓
Agent provides focused guidance
```

### Story Analysis + UAT Flow
```
User: "Generate user stories"
↓
Story Analyst → Creates US-001, US-002, ...
↓
User: "Run UAT tests"
↓
UAT Runner → Executes via Playwright + reports
```

### Large Project (Formation)
```
Copilot Chat → /formation deploy
↓
Orchestrator spawns parallel agents:
├── Frontend Analysis
├── Backend Services
├── Python Stack
├── Dependency Graph
├── Infrastructure
└── Bundle Analysis
↓
Aggregated findings → Final recommendation
```

### TDD Execution
```
/upm feature-name
↓
/formation deploy (TDD Orchestrator)
↓
11+ TDD agents execute RED-GREEN-REFACTOR
↓
Coverage + test results reported
```
